Mapa de similaridade entre textos

O que é?

Cada bolinha é um criativo (um anúncio único). Bolinhas próximas têm textos parecidos; distantes, textos diferentes. Textos idênticos ficam juntos numa bolinha maior, marcada com ×N (quantos são).

E o número?

É o grupo. Mesmo número significa textos quase iguais, em geral variações da mesma mensagem.

Como usar

Veja quantas ideias diferentes o anunciante usa. Um bloco grande é a mesma mensagem repetida; uma bolinha isolada é uma ideia única. Clique para abrir o anúncio.

O que o mapa não mostra

Não compara a imagem do anúncio e não indica desempenho. A posição exata não importa, só quem fica perto de quem.

Detalhes técnicos

A posição é uma projeção determinística; os grupos usam a similaridade de cosseno real entre os textos.

Achados

Cada achado destaca o grupo com a maior fatia de anúncios ativos há 60+ dias. É um indicador de longevidade, não prova de desempenho, gasto ou lucro. A hipótese para testar é um ponto de partida para um criativo original (não é previsão).

Padrões que merecem investigação

As participações usam os anúncios analisados. As taxas excluem datas desconhecidas. O comparador é a segunda categoria mais usada, com desempate em ordem alfabética.
